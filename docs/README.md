# docs

Images referenced by the main [README](../README.md).

Place these two files here, with **exactly** these names:

- **`architecture.png`** — the software / architecture block diagram
  (battery → OneWire2 → firmware layers → screen / PC link).
- **`wiring.png`** — the physical wiring diagram
  (ESP32-C3 SuperMini ↔ 2.4" TFT + EC11 module, with the DATA/ENABLE pull-ups).

Any resolution works; the README shows them as clickable thumbnails that open the
full-size file. Prefer PNG for crisp diagrams.
